🚀 Getting Started

SecureBank is a Next.js application. Follow these steps to run it locally:

  • Navigate to the banking-app folder in your terminal
  • Run npm install to install dependencies
  • Run npm run dev to start the development server
  • Open http://localhost:3000 in your browser

Quick Commands:

cd banking-app && npm run dev
