## 🎨 Design System

### Color Palette

| Color         | Code    | Usage                     |
| ------------- | ------- | ------------------------- |
| Primary       | #1a237e | Buttons, headers, accents |
| Primary Light | #0d47a1 | Button hover states       |
| Accent        | #4caf50 | Links, highlights         |
| Light BG      | #f5f7fa | Section backgrounds       |
| Text          | #333    | Body text                 |
| Borders       | #ddd    | Dividers, input borders   |

### Spacing System

- Small: 12px (gaps, padding)
- Medium: 20px (section padding)
- Large: 40px (component spacing)
- XL: 60px (section spacing)
- XXL: 120px (major sections)

### Typography

- Headers: Font-weight 700-800, letter-spacing -0.5px
- Body: Font-weight 400-500, line-height 1.6-1.8
- Nav: Font-weight 500, uppercase, letter-spacing 0.5px
